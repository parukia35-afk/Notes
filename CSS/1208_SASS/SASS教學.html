1-SASS介紹

sass是css的預處理器(preprocessor)，其目的在減少css的重工，更有效率維護樣式的結構。

sass還能使用變數(現在原生也可以)和函式、流程控制、嵌套(巢狀語法，原生也支援)等

sass與scss

scss是後來推出的更貼近css的寫法，差異如下:

副檔名 語法 說明
.sass 縮排語法
沒有大括號，結尾分號		 語法無法兼容css
.scss 塊語法
寫法與css一致，兼容css		 常用於bootstrap，普及受歡迎，直接將css複製貼上即可使用

2-SASS 資料型態

  1. color:blue,#3498db,rgba(0,0,0,0.5),line-gradient()
  2. nmuber:數字有分有單位(1px、2rem)和無單位
  3. string:有引號字串("Noto Sans TC"),無引號字串(微軟正黑體)
  4. boolean
  5. null
  6. list:用半形空格或逗號做分隔，例如:1.5rem 2rem 3rem或"Helvetica","Arial","sans-serif"
  7. map:類似Javascript的物件，使用key-value配對

3-變數

使用 $ 定義變數。寫在大括號是區域範圍，寫在最外面是全域範圍。

變數可以使用底線_和連字號-，兩者是同樣的

4-流程控制

#if、@else if、@else

使用and、or、not處理判斷運算式

文字

@for迴圈有兩種:through 與 to

@for $i from (start) through (end){...}，包含end

@for $i from (start) from to (end){...}，不包含end

5-嵌套巢狀

雖然很好用，但勿過度使用。應考慮用最少的選擇器選擇到想要的位置，盡量維持三層。

過度使用:編譯過的的選擇器會太長，影響效能與維護姓，不易閱讀，容量也較大。

6-繼承 extend

繼承可以用 % 佔位符選擇器的樣式，避免重複撰寫。

7-函式

funcbox

@function與@mixin有點像，函式必須使用@return回傳值。

函式在呼叫時，無法產生一段css樣式，但@mixin可以。

8-mixin 混合

@mixin可以定義一段可重複使用的樣式區塊

可以使用 @include 像函式一樣被呼叫。

flex-box

mixin + for 建立多個不同顏色的按鈕

使用mixin + @content設計RWD
